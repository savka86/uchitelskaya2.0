💼 Чек-лист продажи проекта

1. Передать ключ владельца

Через кнопку выше. Старый ключ продавца сразу отзывается.

2. Поменять email и контакты

Новый владелец указывает свою почту для отзывов и публичный контакт.

3. Передать инфраструктуру

Отдельно передаются репозиторий GitHub, проект Vercel, Supabase и домен, если он появится. Админка не может автоматически переоформить аккаунты сторонних сервисов.

4. Перевыпустить внешние ключи

Покупателю лучше создать собственный ключ Яндекс Карт и ограничить его своим доменом.

5. Проверить юридические страницы

После смены владельца обновить Политику конфиденциальности, контактные данные и сведения об операторе персональных данных, если они применимы.
