Главное правило: ИИ помогает, но не выдумывает

✅ Можно

  • объяснить сложные термины простыми словами;
  • сократить длинный текст для слайда;
  • составить план защиты;
  • подготовить вопросы жюри;
  • оформить таблицу «задача — метод — результат»;
  • проверить, все ли выводы связаны с задачами.

⛔ Нельзя

  • выдумывать результаты опроса;
  • придумывать проценты, адреса и источники;
  • заменять реальные фото и наблюдения;
  • писать выводы без данных;
  • выдавать текст ИИ за полностью авторскую работу;
  • добавлять факты, которых не было в исследовании.
🧭

Маршрут работы с ИИ

1Назови роль

ИИ должен понимать, что он помощник ученика, а не автор работы.

2Дай тему

Укажи тему: домовой гриб, деревянные дома, признаки поражения.

3Вставь данные

Используй только реальные числа, фото, наблюдения и выводы.

4Запрети выдумки

Добавь фразу: «Не придумывай новые факты и источники».

5Проверь ответ

Сверь каждый текст с материалами проекта перед использованием.

Готовые промпты для проекта

🎤

Речь по слайдам

Для подготовки спокойного выступления на 2–3 минуты.

Ты — помощник ученика 7 класса. Помоги написать речь для защиты проекта о домовом грибе. Используй только мои данные. Не придумывай новые факты. Сделай речь простой, уверенной и логичной.
❓

Вопросы жюри

Для тренировки перед защитой.

Придумай 10 вопросов жюри по проекту о заражённости домов настоящим домовым грибом. К каждому вопросу дай короткий ответ. Не добавляй факты, которых нет в работе.
🧪

Проверка эксперимента

Чтобы объяснить, зачем нужен опыт.

Помоги объяснить эксперимент с образцами древесины простым языком: цель, что сравнивали, что наблюдали, какой вывод можно сделать. Не выдумывай результат.
📊

Цифры и выводы

Для аккуратного описания результатов.

Оформи данные в таблицу: показатель — что означает — какой вывод. Данные: 66 домов, 45 с признаками заражения, 21 без признаков. Не меняй числа.
🗺️

Карта заражённости

Чтобы объяснить визуал проекта.

Помоги подготовить текст для слайда с картой заражённости. Объясни, зачем нужна карта, что она показывает и как помогает жителям. Не добавляй новые адреса.
📋

Памятка жителям

Для практического результата проекта.

Составь памятку для жителей: как заметить возможные признаки домового гриба и что делать для профилактики. Пиши осторожно, без медицинских и юридических обещаний.
