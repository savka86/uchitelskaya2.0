Визуальная формула проекта

Чтобы проект не выглядел хаотично, двигайся по простой цепочке. Каждый блок отвечает на один главный вопрос.

Проблема → Актуальность → Цель → Задачи → Продукт → Результат → Защита

Что не так? Почему важно? Что создаём? Как делаем? Что покажем?

Из чего состоит школьный проект?

1. ТемаКороткое название проекта.
2. ПроблемаЧто нужно решить или улучшить.
3. АктуальностьПочему это важно сейчас.
4. ЦельКакой главный результат нужен.
5. ЗадачиШаги для достижения цели.
6. ЭтапыПлан работы по времени.
7. ПродуктЧто будет создано.
8. ЗащитаКак представить результат.

Что именно нужно оформить?

📝

Тема проекта

Тема должна быть понятной, короткой и показывать, о чём работа.

❗

Проблема

Опиши, что не устраивает и почему это требует решения.

🔥

Актуальность

Покажи, кому и зачем нужен проект именно сейчас.

🎯

Цель

Начни с глагола: создать, разработать, провести, изучить, оформить.

📌

Задачи

Напиши 4–6 конкретных действий, которые приведут к цели.

🎁

Продукт

Это то, что можно показать: сайт, буклет, ИИ-книга, стенд, презентация.

Мини-шаблон паспорта проекта

Название проекта: __________________________ Автор / команда: ___________________________ Наставник: _________________________________ Проблема: __________________________________ Актуальность: ______________________________ Цель: ______________________________________ Задачи: 1. _________________________________________ 2. _________________________________________ 3. _________________________________________ 4. _________________________________________ Продукт проекта: ___________________________ Ожидаемый результат: _______________________ Где будет применён проект: __________________ Как будет проходить защита: ________________

Пример на проекте «МоИИстории»

📚

Идея

Создать персональные ИИ-книги для детей, чтобы повысить интерес к чтению.

  • Проблема: детям трудно заинтересоваться обычным текстом.
  • Цель: создать ИИ-книгу с персональным сюжетом и иллюстрациями.
  • Продукт: цифровая книга, презентация и пример чтения.
🛡️

Что проверяет наставник?

  • понятность цели;
  • логичность задач;
  • связь продукта с проблемой;
  • готовность к защите.

Чек-лист перед защитой

✅ Есть понятная тема
✅ Проблема написана простыми словами
✅ Цель начинается с действия
✅ Задачи идут по порядку
✅ Есть готовый продукт
✅ Результат можно показать
✅ Презентация не перегружена текстом
✅ Есть короткая речь для защиты
